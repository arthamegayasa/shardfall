## S06b Dialog konfirmasi

```
+--------------------------------------------------------------------------------------------------+
|..................................................................................................|
|..................................................................................................|
|..................................................................................................|
|..................................................................................................|
|..................................................................................................|
|..................................................................................................|
|..................................................................................................|
|..................................+--------------------------------+..............................|
|..................................|                                |..............................|
|..................................|       Abandon this run?        |..............................|
|..................................|                                |..............................|
|..................................|   >[ Stay ]      [ Abandon ]   |..............................|
|..................................|                                |..............................|
|..................................+--------------------------------+..............................|
|..................................................................................................|
|..................................................................................................|
|..................................................................................................|
+--------------------------------------------------------------------------------------------------+
```

- Fokus awal selalu pilihan aman (Stay). Esc = Stay. Kiri/kanan pindah tombol.
- Hanya untuk: Abandon Run, Reset Controls, hapus data simpan. Tidak pernah untuk beli, reroll, atau memilih kartu.
- Tombol berbahaya (Abandon) memakai teks biasa, bukan merah. Merah hanya untuk bahaya di arena.
