## Interaksi
| Input | Hasil |
|---|---|
| Panah atas/bawah, W/S, hover | Pindah fokus menu |
| Enter, Space, klik | Buka layar terpilih. Continue memuat autosave ke toko terakhir |
| Begin saat ada autosave | Pola "Press again": tekan dua kali karena run lama akan ditimpa |
| Esc | Tidak ada |

## Catatan
- Continue hanya tampil bila ada autosave run (`shardfall.run.v1`, architecture.md bagian 12), dan menjadi fokus awal. Tanpa autosave, fokus awal Begin.
- Saldo Silt hanya tampil bila Silt aktif (Tingkat B).
- Menu di bawah tengah agar judul dan arena menjadi pusat perhatian. Menu di sepertiga bawah, di luar pita DoF bawah.
- Credits membuka panel teks sederhana (isi dari `docs/credits.md` yang diekspor ke string table), Esc menutup.
