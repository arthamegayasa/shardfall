## Interaksi (S04 dan S04b)
| Input | Hasil |
|---|---|
| 1, 2, 3 | Pilih kartu itu langsung (1 input) |
| Atas/bawah, W/S, hover | Pindah fokus |
| Enter, Space, klik | Pilih kartu yang difokus |
| Esc | Buka Jeda (pilihan tidak bisa dilewati) |

- Kunci input 300 ms saat layar muncul. Tombol yang tertahan dari Pulse harus dilepas dulu.
- Setelah memilih: kartu terpilih berkilau emas 150 ms, lalu layar berikutnya di antrean (level-up berikutnya, atau toko).
